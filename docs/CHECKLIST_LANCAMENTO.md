# Checklist de lançamento

- [ ] Proprietário Expo e identificadores aprovados.
- [ ] Contas Play/Apple com identidade, contratos e pagamentos concluídos pelo titular.
- [ ] Login EAS CLI e projeto autorizado vinculados.
- [ ] Homologação, HTTPS e API mobile validados com contas sintéticas.
- [ ] Cadastro/convite, recuperação e exclusão dentro/fora do app implementados.
- [ ] Gravação/transcrição nativa e quotas testadas em aparelhos.
- [ ] Billing aprovado, recibos, renovação, cancelamento e restauração em sandbox.
- [ ] URLs de suporte/privacidade/exclusão e revisão responsável dos documentos.
- [ ] Data Safety/App Privacy, idade e permissões conferidos com o produto final.
- [ ] Ícone/splash/imagens finais; capturas verdadeiras.
- [ ] Lint, tipos, testes, doctor e bundles com evidências.
- [ ] APK/AAB/IPA assinados reais e assinatura/versões conferidas.
- [ ] Android/iPhone: teclado, safe areas, rede lenta/offline, troca de conta, agenda, valores e confirmações.
- [ ] Backup/restauração ensaiados; carga e observabilidade revisadas.
- [ ] Conta/instruções segregadas para revisor.
- [ ] Teste interno/fechado/TestFlight aplicáveis e feedback real concluídos.
- [ ] Autorizações separadas para custo, upload, revisão e publicação pública.

Só marcar release-policy.json após evidência. Nunca remover bloqueios apenas para conseguir executar um comando.
